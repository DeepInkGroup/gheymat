Gheymat

A minimal, glassy PWA showing live currency, gold, coin and crypto prices in Toman — built with Next.js and sourced from baha24.com.

Next.js 16 React 19 TypeScript Tailwind CSS v4 PWA / iOS glass UI
Open live preview View source on GitHub

What it does

💱

28 live instruments

Major currencies, gold & coins (Emami, Azadi, Mithqal), and top crypto — all in Toman.

🛡️

Resilient data layer

Server-side proxy caches baha24's response and falls back gracefully on rate limits or errors.

🏳️

Real flag icons

Bundled SVG flags (not emoji) for consistent rendering across Windows, iOS, and every browser.

📱

Installable on iPhone

Full PWA manifest, offline service worker, and an automatic frosted-glass UI when launched standalone.

🌗

Light & dark aware

Every surface, gradient and contrast ratio is tuned for both color schemes.

📐

Fully responsive

1 / 2 / 3-column layouts across phones, tablets and desktops with zero horizontal overflow.
